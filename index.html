Caméra, données et connexion

Glissez un doigt sur la scène pour regarder devant, derrière ou sur le côté. Pincez à deux doigts pour zoomer. Suivi, Paysage et Profil recentrent la caméra. En mode paysage, le bouton Données replie les compteurs.

Rouler libre télécharge dans le rayon choisi les routes et objets OSM utilisés par le décor. Le secteur est préparé dans les deux sens disponibles ; appuie sur Lancer puis choisis le sens dans l’écran de sortie. Les villes affichées sous les flèches sont des indications tirées des noms OSM proches, pas une garantie d’itinéraire jusqu’à la ville.

Le relief libre est estimé à partir du modèle Copernicus DEM GLO-90 via l’API d’altitude Open-Meteo ; la résolution du modèle est d’environ 90 m. Si le service est inaccessible, le parcours reste utilisable mais la pente peut être incomplète.

Les haies cartographiées sont complétées par des haies estimées sur les portions rurales sans bâtiments voisins. Routes annexes et ronds-points suivent les données OpenStreetMap ; leurs alentours peuvent être incomplets.

Hébergez ce fichier en HTTPS (GitHub Pages convient). Pour le trainer et le cardio : Chrome Android ou navigateur compatible Web Bluetooth. La démonstration fonctionne sans capteur.
